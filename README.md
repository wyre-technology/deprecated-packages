# Deprecated WYRE packages

WYRE Technology's GitHub Container Registry packages moved to the **WYRE-AI** org as part of an
org-wide migration (2026-08-25). Packages published under `ghcr.io/wyre-technology/*` are no
longer updated and will not receive further releases or security fixes.

**If you're pulling an image from `ghcr.io/wyre-technology/<name>`, switch to
`ghcr.io/WYRE-AI/<name>`** — same image, same versioning, actively maintained.

This repository exists only to host this explanation; it links from the deprecated packages'
GHCR pages via each image's `org.opencontainers.image.source` label. It contains no code.
